ORGANISMES — blocs complexes / sections réutilisables

Header (organisme)

Composition : Logo, NavLinks (Accueil, Films, Réservations, Contact), Role-area (Login/Register OR UserMenu OR EmployeeLink OR AdminLink), Notifications icon.

Inputs : user (nullable), role, notificationsCount.

Outputs : openLogin, navigate.

Comportement : adaptatif selon rôle.

Footer (organisme)

Composition : Liste cinémas (nom, adresse, phone, horaires), liens utiles, mentions légales.

Inputs : cinemas[], links[].

Sidebar (Admin / Employee)

Composition : liste plats de nav (non hiérarchique ici).

Inputs : role, items[] (libellés + route + icon).

Outputs : select.

MovieList (catalog)

Composition : grille ou liste de FilmCard, filtres (cinéma/genre/jour), pagination.

Inputs : films[], filters.

Outputs : filterChange, selectFilm.

ReservationPanel (organisme)

Composition : sélection cinéma/film/séance, seat map (Seat components), récapitulatif prix, CTA réservations.

Inputs : cinemas[], film, sessionTimes[], availableSeats.

Outputs : reserve.

AdminTable

Composition : table de données (films, séances, employés) + actions (edit/delete).

Inputs : columns[], rows[], selectable.

Outputs : edit, delete, bulkAction.

IncidentManager

Composition : liste incidents + form de création + statuts.

Inputs : incidents[].

Outputs : create, updateStatus.

AuthForm (organisme)

Composition : FormField pour email/mot de passe + actions (submit, forgot password).

Inputs : mode (login/register), errors.

Outputs : submit, forgot.

NotificationsCenter

Composition : liste NotificationItem, mark-as-read, clear.

Inputs : notifications[].

Outputs : open, markRead, clearAll.
