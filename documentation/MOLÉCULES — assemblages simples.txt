MOLÉCULES — assemblages simples

FormField

Composition : Label + Input/Textarea/Select + Error message + Hint.

Inputs : label, control (formControlName), error, hint.

Usage : formulaire d’inscription, login.

SearchBar

Composition : Input + Icon (search) + Clear button.

Inputs : value, placeholder, debounce.

Outputs : search (debounced).

NavLink

Composition : Icon + Label.

Inputs : label, route, active.

Usage : header/menu/sidebars.

FilmCard

Composition : Poster, titre, âge, rating, tags (coup de cœur), CTA (voir séances / réserver).

Inputs : film object, variant (grid/list), showTags.

Outputs : selectFilm, openDetail.

RatingStars

But : afficher / saisir note.

Inputs : value (0–5), readOnly, size.

Outputs : rateChange.

Seat (single)

But : case représentant un siège.

Inputs : status (available/booked/selected/pmr), row, number.

Outputs : toggleSelect.

Accessibilité : aria-pressed pour sélection.

NotificationItem

Composition : Icon + message + timestamp + action (ex : Voir).

Inputs : notification.

QRCodeDisplay

But : afficher QR code pour billet.

Inputs : data, size.

Outputs : scanned (optionnel).

ModalTitleBar

Composition : Titre + Close button + optional actions.

Inputs : title, subtitle.
